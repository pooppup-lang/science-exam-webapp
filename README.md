# 🔬 ระบบทำข้อสอบวิทยาศาสตร์ออนไลน์ (Science Examination Web App)

ระบบทำข้อสอบออนไลน์สำหรับวิชาวิทยาศาสตร์ พัฒนาด้วย **Google Apps Script (GAS) + Google Sheets** พร้อมฟังก์ชันความปลอดภัยในการสอบ (Anti-Cheating), ระบบจับเวลาถอยหลัง (Timer), และการจำกัดสิทธิ์สอบ 1 คนต่อ 1 ครั้ง

---

## 🌟 ฟังก์ชันเด่นของระบบ (Core Features)

### 1. ⏱️ ระบบจับเวลาถอยหลัง (Countdown Timer & Auto-Submit)
* ครูผู้สอนสามารถกำหนดเวลาในการทำข้อสอบได้ตามต้องการ (เช่น 15, 30 นาที หรือใส่ 0 เพื่อไม่จำกัดเวลา)
* มีแถบนาฬิกานับถอยหลังและ Progress Bar แสดงเวลาที่เหลือแบบเรียลไทม์
* แถบเวลาเปลี่ยนสีเตือน (สีฟ้า -> สีส้มเมื่อเหลือน้อยกว่า 5 นาที -> สีแดงกะพริบเมื่อเหลือน้อยกว่า 1 นาที)
* **ส่งข้อสอบอัตโนมัติทันที** เมื่อหมดเวลา (`00:00`) แม้นักเรียนยังทำไม่ครบทุกข้อ

### 2. 🛡️ ระบบตรวจจับการสลับหน้าจอ (Anti-Cheating Detection)
* ดักจับ Event `visibilitychange` และ `window.blur` เมื่อนักเรียนสลับแท็บ ย่อหน้าจอ หรือคลิกออกนอกหน้าต่างสอบ
* แสดงหน้าต่างแจ้งเตือนทันทีพร้อมนับจำนวนครั้งที่สลับหน้าจอ
* บันทึกจำนวนครั้งที่สลับหน้าจอ และแสดง Badge เตือนในหน้าต่างผลคะแนนของครู (สีเขียว: 0 ครั้ง, สีส้ม: 1-2 ครั้ง, สีแดง: 3 ครั้งขึ้นไป)

### 3. 🔒 จำกัดสิทธิ์การทำข้อสอบ 1 คน ต่อ 1 ครั้ง (Single Submission Lock)
* ตรวจสอบความซ้ำซ้อนจาก **รหัสห้องสอบ + ชั้น/ห้อง + เลขที่**
* ป้องกันไม่ให้นักเรียนสอบซ้ำเพื่อปั่นคะแนน
* ครูมีปุ่ม **"อนุญาตสอบใหม่"** สำหรับลบผลสอบเดิมออก เพื่อเปิดโอกาสให้นักเรียนสอบใหม่ได้ (กรณีเกิดเหตุขัดข้องหรือให้สอบแก้ตัว)

### 4. 🧮 เครื่องคิดเลขในตัว (Built-in Scientific/Basic Calculator)
* นักเรียนสามารถเปิด/ปิดเครื่องคิดเลขบนหน้าจอเพื่อใช้คำนวณโจทย์วิชาฟิสิกส์/เคมีได้โดยไม่ต้องออกจากหน้าจอสอบ

### 5. 👨‍🏫 ระบบครูผู้สอน (Teacher Dashboard)
* สมัครสมาชิก / เข้าสู่ระบบด้วยรหัสผ่านเข้ารหัส SHA-256
* สุ่มข้อสอบตามสัดส่วนระดับความยาก: ง่าย (Easy), ปานกลาง (Medium), ยาก (Hard)
* ดูผลคะแนนแบบเรียลไทม์ (ชื่อ, ชั้น, เลขที่, คะแนน, เปอร์เซ็นต์, จำนวนครั้งที่สลับหน้าจอ)
* ปิดห้องสอบเมื่อสิ้นสุดช่วงเวลาสอบ

## 🚀 ขั้นตอนการนำขึ้น GitHub (How to Push to GitHub)

### 1. สร้าง Repository บน GitHub
1. เข้าไปที่ [GitHub](https://github.com) แล้วล็อกอินเข้าบัญชีของคุณ
2. กดปุ่ม **New** (หรือเครื่องหมาย `+` มุมขวาบน) เพื่อสร้าง Repository ใหม่
3. ตั้งชื่อ Repository เช่น `science-exam-webapp`
4. เลือกเป็น **Public** หรือ **Private** ตามต้องการ
5. **ไม่ต้อง** ติ๊กถูกที่ *"Add a README file"* (เพราะเรามีไฟล์ในเครื่องแล้ว)
6. กด **Create repository**

### 2. นำโค้ดในเครื่องขึ้น GitHub (Push Commands)
เปิด Terminal หรือ PowerShell ที่โฟลเดอร์โปรเจกต์นี้ แล้วรันคำสั่งตามลำดับดังนี้:

```bash
# 1. ตรวจสอบการเชื่อมต่อกับ GitHub Repository ของคุณ
git remote -v

# 2. เมื่อมีการแก้ไขโค้ดในอนาคต สามารถสั่ง Push ได้ด้วยคำสั่ง:
git add .
git commit -m "update: รายละเอียดการแก้ไข"
git push origin main
```

## 🛠️ ขั้นตอนการติดตั้งบน Google Apps Script

1. สร้าง Google Spreadsheet ใหม่ที่ [Google Sheets](https://sheets.new)
2. ไปที่เมนู **ส่วนขยาย (Extensions) > Apps Script**
3. สร้างไฟล์:
   * ไฟล์สคริปต์ `Code.gs` : คัดลอกโค้ดจาก [`Code.gs`](file:///c:/Users/Hp321/Documents/wep_app_w3/Code.gs) ไปวาง
   * ไฟล์ HTML `index.html` : คัดลอกโค้ดจาก [`index.html`](file:///c:/Users/Hp321/Documents/wep_app_w3/index.html) ไปวาง
4. ในฟังก์ชันของ `Code.gs` เลือกรันฟังก์ชัน `setupRoomSystem()` หนึ่งครั้งเพื่อให้ระบบเตรียมโครงสร้างตารางชีตและคลังข้อสอบ
5. กดปุ่ม **ทำให้ใช้งานได้ (Deploy) > การทำให้ใช้งานได้ใหม่ (New deployment)**
   * เลือกประเภท: **เว็บแอป (Web app)**
   * ดำเนินการในฐานะ: **ฉัน (Me)**
   * ผู้มีสิทธิ์เข้าถึง: **ทุกคน (Anyone)**
6. คัดลอก Web App URL เพื่อนำไปให้นักเรียนและครูใช้งาน
