# 🔬 ระบบทำข้อสอบวิทยาศาสตร์ ม.ปลาย ออนไลน์ (Science Exam Web App)

เว็บแอปพลิเคชันระบบทำข้อสอบออนไลน์สำหรับวิชาวิทยาศาสตร์ระดับมัธยมศึกษาตอนปลาย (**ชีววิทยา, เคมี, ฟิสิกส์**) พัฒนาด้วย **Google Apps Script (GAS) + Google Sheets** พร้อมระบบความปลอดภัยและการควบคุมการสอบระดับสูง ไม่ละเมิดข้อมูลส่วนบุคคล (PDPA-Friendly)

---

## 🌟 จุดเด่นและฟังก์ชันการทำงานใหม่ (Key Features)

### 1. 🧬 แยกหมวดวิชาวิทยาศาสตร์ ม.ปลาย ชัดเจน
* ครูผู้สอนสามารถเลือกสร้างห้องสอบเฉพาะวิชาได้:
  * 🧬 **ชีววิทยา (Biology)**: โครงสร้างเซลล์, การแบ่งเซลล์ (Mitosis/Meiosis), สารพันธุกรรม (DNA/RNA), สังเคราะห์แสง
  * 🧪 **เคมี (Chemistry)**: พันธะเคมี, กรด-เบส, ปริมาณสารสัมพันธ์, ตารางธาตุ
  * ⚡ **ฟิสิกส์ (Physics)**: กฎการเคลื่อนที่ของนิวตัน, พลังงานและงาน, แสงและการหักเห, ไฟฟ้า
  * 🔬 **วิทยาศาสตร์ทั่วไป (General Science)**
* สุ่มโจทย์ตามระดับความยาก: ง่าย (Easy), ปานกลาง (Medium), ยาก (Hard)

### 2. 🔑 กู้คืนรหัสผ่านด้วย PIN 4 หลัก และคำถามกันลืม (Privacy First)
* **ปลอดภัย 100% ไม่ต้องใช้อีเมลจริง**: ไม่ต้องกังวลเรื่องข้อมูลส่วนบุคคลหลุดรั่ว เหมาะอย่างยิ่งสำหรับการทำโปรเจกต์ส่งอาจารย์
* **ตอนสมัครครู**: ตั้งค่ารหัส **PIN กู้คืน 4 หลัก** (เช่น `1234`) และเลือก **คำถามกันลืม 1 ข้อ** (เช่น สัตว์เลี้ยงตัวแรกของคุณชื่ออะไร?) พร้อมระบุคำตอบ
* **ตอนลืมรหัสผ่าน**: เพียงกรอกชื่อผู้ใช้ ตอบคำถามกันลืม และใส่รหัส PIN ให้ถูกต้อง ก็สามารถตั้งรหัสผ่านใหม่ได้ทันที

### 3. ⏱️ นาฬิกาจับเวลาลอยตามหน้าจอ (Sticky Floating Header)
* แถบเวลาและ Progress Bar ตรึงติดอยู่ด้านบนของหน้าจอเสมอ แม้จะเลื่อนจอลงไปทำข้อลึกๆ ก็มองเห็นเวลาได้ตลอดเวลา
* มีปุ่มลัด **🧮 เปิด/ปิดเครื่องคิดเลขวิทยาศาสตร์** ได้ทันทีจากแถบด้านบน
* แถบเวลาเปลี่ยนสีเตือน (ฟ้า -> ส้มเมื่อเหลือน้อยกว่า 5 นาที -> แดงกะพริบเมื่อเหลือน้อยกว่า 1 นาที)
* **ส่งข้อสอบอัตโนมัติทันที** เมื่อเวลาหมด (`00:00`)

### 4. ⚠️ ตรวจจับการสลับหน้าจอ -> รีเซ็ตข้อสอบเริ่มใหม่ทันที (Anti-Cheat Reset)
* หากนักเรียนสลับแท็บ ย่อหน้าจอ หรือคลิกออกนอกหน้าต่างสอบ ระบบจะแสดงหน้าต่างเตือนสีแดงทันที
* **บทลงโทษ**: ล้างคำตอบเดิมทั้งหมด และสุ่มชุดข้อสอบใหม่ให้นักเรียนเริ่มทำใหม่ตั้งแต่ข้อแรกทันที พร้อมบันทึกจำนวนครั้งรายงานครูผู้สอน

### 5. 🔀 สลับตัวเลือก ก-ข-ค-ง และสลับข้อ (Choice & Question Shuffling)
* สุ่มสลับทั้งลำดับข้อสอบ และสลับตำแหน่งตัวเลือก ก, ข, ค, ง ของแต่ละข้อ ทำให้ข้อสอบของนักเรียนแต่ละคนไม่เหมือนกัน ป้องกันการลอกได้อย่างสมบูรณ์
* ตรวจข้อสอบด้วยข้อความตัวเลือก (Choice Text Matching) ป้องกันปัญหาการตรวจคะแนนคลาดเคลื่อน

### 6. 👥 แยกบัญชีครูออกจากกัน 100% (Strict Teacher Isolation)
* ครูแต่ละท่านจะมองเห็นและจัดการได้เฉพาะห้องสอบและผลคะแนนที่ตนเองสร้างขึ้นเท่านั้น ป้องกันไม่ให้ครูต่างคนเข้าถึงข้อมูลของกันและกัน

### 7. 🎨 ปรับโฉมหน้าตา UI/UX ใหม่ (Modern Clean Design)
* ใช้แบบอักษร Google Fonts (`Prompt` และ `Sarabun`) อ่านง่าย สบายตา
* ออกแบบการ์ดข้อสอบพร้อม Badge สีแยกวิชาและระดับความยากชัดเจน รองรับการใช้งานทั้งบนมือถือ แท็บเล็ต และคอมพิวเตอร์

## 🛠️ ขั้นตอนการติดตั้งบน Google Apps Script

1. สร้าง Google Spreadsheet ใหม่ที่ [Google Sheets](https://sheets.new)
2. ไปที่เมนู **ส่วนขยาย (Extensions) > Apps Script**
3. สร้างไฟล์:
   * ไฟล์สคริปต์ `Code.gs` : คัดลอกโค้ดจาก [`Code.gs`](file:///c:/Users/Hp321/Documents/wep_app_w3/Code.gs) ไปวาง
   * ไฟล์ HTML `index.html` : คัดลอกโค้ดจาก [`index.html`](file:///c:/Users/Hp321/Documents/wep_app_w3/index.html) ไปวาง
4. ในฟังก์ชันของ `Code.gs` เลือกรันฟังก์ชัน `setupRoomSystem()` หนึ่งครั้งเพื่อให้ระบบเตรียมชีตและคลังข้อสอบ ม.ปลาย
5. กดปุ่ม **ทำให้ใช้งานได้ (Deploy) > การทำให้ใช้งานได้ใหม่ (New deployment)**
   * เลือกประเภท: **เว็บแอป (Web app)**
   * ดำเนินการในฐานะ: **ฉัน (Me)**
   * ผู้มีสิทธิ์เข้าถึง: **ทุกคน (Anyone)**
6. คัดลอก URL เพื่อนำไปใช้งาน
